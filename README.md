# Rush Hour, Accra

A lightweight browser arcade racer inspired by Accra traffic.

## Project status

This repository is being initialized from the supplied single-file prototype. The first implementation milestone preserves the arcade game while keeping all gameplay collectibles strictly non-monetary and non-redeemable.

## Safety and economy boundary

- Collectibles are local gameplay score items only.
- Scores, boosts, and leaderboard points have no cash value and cannot be withdrawn, transferred, or exchanged.
- Sponsor placements are optional and provide no gameplay reward or score advantage.
- No ad view creates a financial or redeemable player liability.

## Run locally

Open `index.html` in a modern browser. No build step is required.

## Quality checks

Run `npm test` to execute the lightweight repository checks.
